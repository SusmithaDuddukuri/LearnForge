# Release Quality Checklist

- [ ] Application starts using the documented setup.
- [ ] Sign-in and sign-out workflows are checked.
- [ ] Student and faculty permissions are verified.
- [ ] Course and lesson navigation are checked.
- [ ] Progress persistence is tested.
- [ ] Layout is reviewed at different screen sizes.
- [ ] No credentials or private data are included in the changes.
- [ ] Relevant automated tests pass.
